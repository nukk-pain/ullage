# ullage

ullage is a wine cellar that an AI agent manages through MCP. The agent can track bottles, record cellar pours and outside tastings, protect bottles with holds, and export cellar data. SQLite is the default store, so a standard local installation needs no server or access token.

## Install with an agent

Tell your agent:

> Check https://github.com/nukk-pain/ullage and install it.

The agent should follow [the installation and operation runbook](docs/agent-install.md). It covers fresh installs, upgrades, runner setup, safe cellar writes, and troubleshooting.

The npm package is not published yet. Install from a Git checkout as described in the runbook.
